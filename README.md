# Cedden Lab

Academic website of Doga Cedden, covering research, publications, preprints, invited talks, awards, news and CV.

## Publishing

This folder contains the complete static website. Publish the `main` branch from its root using GitHub Pages. No build step or package installation is needed.

## Editing

Each page is a separate HTML file. Shared appearance is in `style.css`; the mobile menu is in `site.js`. Research figures and the downloadable CV are in `assets/`.

Figure attribution and source links are provided alongside the figures. Third-party material retains its original license.
